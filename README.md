# AppForSets
---
Учебное приложение для выполнения базовых операций над множествами 

## Запуск
---
Проект разрабатывался на версии Python 3.14.8. Совместимость с другими версиями не проверялась.

1. Клонируйте репозиторий:
```bash
git clone https://github.com/artvano/App_for_sets
cd App_for_sets
```
2. Создайте и активируйте виртуальное окружение:
```bash
py -m venv .venv
.venv\Scripts\Activate.ps1
```
3. Установите зависимости:
```bash
pip install -r requirements.txt
```
4. Запустите программу
```bash
py main.py
```
## Функционал программы
---
Программа предоставляет ряд функций для выполнения операций над множествами:
* Дополнение до универсального множества
* Множество всех подмножеств
* Мощность 
* Объединение множеств
* Пересечение множеств
* Разность множеств
* Симметрическая разность множеств

Операции над множествами реализованы собственными функциями для учебной практики (исходный код функций находится в файле `sets_functions.py`). В Python для типа `set` уже есть операторы объединения (`|`), пересечения (`&`), разности (`-`) и симметрической разности (`^`), а также методы `.union()`, `.intersection()`, `.difference()` и `.symmetric_difference()`. Функции проекта принимают списки (`list`); при этом `union` использует `set` внутри для удаления дубликатов.

## Инструкция по интерфейсу программы.
---
Для осуществления операций над множествами нужно ввести содержимое множеств: универсальное множество(U), множество A, и множество B. Элементы множеств вводятся поочерёдно через ", "(запятую и пробел). Поля для ввода множеств появляются последовательно(после ввода значений одного множества и нажатия на кнопку `Далее` появляется поле ввода следующего множества). После ввода содержимого всех множеств и нажатия на кнопку `Подтвердить` выводится содержимое множеств без отсутствующих в универсальном множестве и повторяющихся элементов, и появляется окно выбора функции (дальнейшие операции выполняются с множествами `A` и `B` после этой проверки). После нажатия на желаемую функцию, её результат появляется в основном окне.
